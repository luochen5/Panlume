# Panlume
## About / 项目介绍

Panlume 盘灯是一个本地优先的 Windows 桌面学习项目，用于公开 A 股行情观察、个人研究记录和可追溯的研究报告生成。

我是一名非计算机专业的大学生，这个项目主要用于学习 Python 软件工程、桌面应用开发、数据处理和本地模型应用。项目在 AI 编程工具的协助下开发，我负责需求、功能验证和发布。

它目前仍是持续学习中的个人项目，并非成熟的专业金融软件。欢迎开发者或用户通过 Issues 提出改进建议、分享使用反馈或给予技术指导。提出建议时，请尽量附上操作步骤、界面截图或不含个人数据的错误信息。

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作，不自动交易，也不承诺收益。
## About

Panlume is a local-first Windows desktop learning project for observing public A-share market data, keeping personal research records, and generating traceable research reports.

I am a university student majoring outside computer science. I use this project to learn Python software engineering, desktop application development, data processing, and local-model integration. It is developed with assistance from AI coding tools, while I define the requirements, verify the features, and publish the releases.

This is an ongoing personal learning project rather than a mature professional financial application. Feedback, improvement suggestions, and technical guidance from developers and users are welcome through Issues. Please include reproduction steps, screenshots, or error details without personal data when appropriate.

Panlume is intended only for public-information processing, personal research records, and software learning. It does not connect to external accounts, perform external operations, trade automatically, or promise returns.
