# Panlume v2.0.0 正式版验收标准 v4

1. 程序、PyInstaller 输入、Inno Setup、构建脚本、测试和 README 统一为 2.0.0。
2. 保留数据库结构版本 6、历史原文、真实请求门控和既有安全边界。
3. 统一事实包具有稳定 JSON、内容哈希、完整规则字段和可追溯证据。
4. 无模型时固定报告完整；模型只追加叙述，异常只回退叙述。
5. 报告中心、整页报告成果、预设、JSON/Markdown 导出和证据跳转可用。
6. Ollama 管理不自动下载、不伪造进度、不直接修改内部文件。
7. 观察对象最多 10 个，启停和顺序保留；MACD/RSI 口径与数据不足行为明确。
8. 四语言保存后重启生效，历史记录保留原文；12 个导航入口在小窗口可见。
9. Windows EXE、便携、安装卸载、个人数据保留、真实 14B 摘要、Defender 扫描和用户界面检查有真实记录。
10. Release 提供安装包、便携 ZIP、源码 ZIP 和 SHA-256；不发布个人数据、日志、备份、虚拟环境、验收记录或模型文件。
