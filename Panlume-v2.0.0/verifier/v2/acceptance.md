# D7 v0.7.0 双语发布候选验收标准 v2

目标：在 D6 发布候选上只增加简体中文与 English 支持，保持核心规则、数据库结构和真实请求边界不变。

1. 版本为 0.7.0，保留 D1～D6 页面、命令、数据库结构版本 6 和真实请求门控。
2. 独立“语言 / Language”板块只处理语言选择、保存和重启说明；保存后当前窗口不切换。
3. 公开桌面入口的新安装默认 English；旧设置 JSON 缺少 `language` 键时继续使用简体中文；非法语言严格拒绝。
4. 当前进程内新生成的观察摘要、事件摘要、本地复盘和演示固定模板继续使用启动语言，重启后统一切换。
5. 英文固定模板保留代码、完整时间、关键数值、来源和确认状态，并通过既有确定性校验；模型失败仍返回完整模板。
6. 历史摘要、复盘、规则告警、质量消息、JSON、审计和原始记录不改写、不回填翻译；英文界面只翻译展示标签。
7. 相同事实已有复盘时继续幂等返回旧报告；已有演示再次运行只读，个人数据库不参与。
8. 英文 980×640 小窗口的 10 个导航入口完整可见，长页面与结果可滚动；缺少英文资源时回退中文。
9. 英文 README 为首页，中文 README 与 D7 使用说明保留；构建脚本、便携包和安装包版本同步至 0.7.0。
10. 双语专项、全量和干净解压测试通过；源码包排除数据库、缓存、日志、虚拟环境、构建产物与 verifier 工作记录。
11. 本轮不执行真实行情、真实 Ollama 或云端请求。Windows EXE、便携版、安装卸载、真实模型成功摘要和杀毒表现留作用户后续实机验收。
