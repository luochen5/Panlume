# D6 v0.6.0 发布候选验收标准 v1

目标：整合 D1～D5 已验收能力，形成可独立演示、可复验、可交付的离线学习版发布候选，不扩张业务策略。

1. 版本为 0.6.0，保留 D1～D5 页面、命令、数据库结构版本 6 和真实请求门控。
2. “离线演示”在既有独立 `analysis-test.db` 中复用模拟行情与真实规则提醒，补充固定模板摘要、本地复盘，并读取数据体检和事件摘要历史；个人数据库不参与。
3. 首次演示覆盖观察、断网恢复、规则事件、零模型调用模板回退、复盘、体检和历史证据；结果如实展示，不虚构模型成功。
4. 已完成演示再次运行时仅读取，全部数据库表逐行不变，不重复追加摘要或复盘。
5. 旧版或不完整演示不自动删除、覆盖、修复或补写；给出明确状态与新的隔离目录建议。非法演示路径继续被拒绝。
6. 启动不请求真实行情、Ollama 或云端；活动任务阻止直接关闭，空闲时正常关闭；备份可重新打开且保留已提交数据。
7. 演示使用后台任务和主线程 UI 队列，小窗口可滚动到结果，失败时不自动重试。
8. 新增测试覆盖完整演示、幂等只读、数据隔离、异常状态、生命周期和界面；全量与干净解压复验通过。
9. README、D6 使用说明、构建和安装脚本同步至 0.6.0；源码包排除数据库、缓存、日志、虚拟环境、构建产物与 verifier 工作记录。
10. 本轮无需 Windows 实机或联网；Windows EXE、便携版、安装卸载与杀毒表现留作用户后续统一实机验收。
