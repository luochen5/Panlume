Panlume 盘灯 v2.0.0 便携四语言学习版

使用方法
1. 先完整解压 ZIP，再进入 Panlume 文件夹，双击 Panlume.exe。
2. Panlume.exe、_internal 文件夹和 panlume.portable 必须一起保留，不能只复制 EXE。
3. 新安装默认 English。打开 Language / 语言，选择简体中文并保存，重启后生效。
4. 首次启动只初始化个人数据库，不请求真实行情，不调用 Ollama，也不访问云端。
5. F11 切换全屏，Esc 退出全屏。页面内容较高时，可滚动右侧滚动条或鼠标滚轮。

主要功能
- 统一事实包、完整固定模板、报告预设、JSON/Markdown 导出和整页报告成果；
- 可选 Ollama 叙述，模型不可用或输出异常时只回退叙述，不丢程序事实；
- Ollama 安装/连接检测、模型选择、真实下载进度、取消和确认删除；
- 最多 10 个观察对象、启停与排序，确定性 MACD/RSI；
- English、简体中文、繁體中文和日本語，历史记录保留原文；
- 本地模拟观察、CSV 历史回放、数据体检、事件追溯、备份和保守清理；
- 独立 analysis-test.db 的一键整合离线演示，个人数据库不参与；
- 受控真实短验收，必须由用户当次明确确认，使用独立测试数据库。

个人数据
便携标记存在时，个人数据默认保存在与 Panlume 文件夹同级的 PanlumeData 目录。
例如：
Panlume-portable\
  Panlume\
    Panlume.exe
    _internal\
    panlume.portable
  PanlumeData\

安装版与便携版的个人数据默认分开。PANDENG_DATA_DIR 环境变量可另行指定隔离目录。
删除便携程序文件夹不会自动删除 PanlumeData。需要删除个人数据时，请先备份并自行确认。

当前边界
项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。
真实持仓只能由用户手动确认更新，模型无权修改。
本地模型只负责摘要，不能修改原始数据和程序结论。
敏感配置通过环境变量管理，并提供示例文件。
程序不自动下单，不承诺收益，不构成投资建议。
不需要管理员权限，不安装驱动，不设置开机启动。
不需要关闭杀毒软件或添加大范围排除目录。
