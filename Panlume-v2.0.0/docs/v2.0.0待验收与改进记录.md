## 1. 滚动条滑块不可见（优先复查）

用户实机反馈：复古上下箭头已消失，但没有看到现代滑块。

暂不归因于用户显示设置。明天需要同时检查：

- 页面内容没有溢出时，滚动条按设计隐藏，是否属于正常现象；
- 页面内容已经溢出时，滑块是否仍不可见；
- `DesktopTheme` 中自定义 `TScrollbar` layout 的 trough/thumb 配置是否导致拇指未显示；
- 浅色、深色主题下滑块与背景色的对比度；
- `ScrollablePage` 使用 `place` 覆盖显示滚动条时，是否被内容遮挡或宽度过小；
- 基础 EXE 与便携 EXE 的实际显示是否一致。

验收标准：需要滚动的页面出现清晰、宽度适中、可拖动的现代滑块；无内容溢出时不强制显示；不改变现有滚动行为。

## 2. 本地 AI 摘要展示区域过小（核心展示改进）

用户反馈：本地 AI 生成摘要是项目运行成果和核心目的，当前展示位置与面积不够突出。

明天建议：

- 增大报告结果区域的默认高度与可用空间；
- 调整报告页“设置/预览/结果”的主从布局，让结果区成为视觉主体；
- 模型叙述生成后提供清晰可见的位置，必要时自动定位到“可选模型叙述区”；
- 保留完整程序事实区、事实包预览和原始证据追溯，不用模型叙述替代事实；
- 检查小窗口与高 DPI 下的滚动、选择复制和按钮可达性；
- 观察页的本地摘要文本框也一并评估，不只改报告中心。

验收标准：固定模板和模型成果都易于阅读，模型成功/回退状态清晰，长文本不挤压主要操作按钮。

- 生成完成后自动跳转到成果页，并保留 JSON/Markdown 导出、相关历史与原始证据入口。
- 本地观察摘要复用同一成果展示入口，不新增第二套报告或事实链路。
- 保持小窗口、高 DPI、长文本滚动和选择复制可用。
