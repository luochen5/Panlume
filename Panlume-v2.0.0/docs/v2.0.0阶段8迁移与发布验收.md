## 真实 Ollama 验收

- 本机 Ollama 在线，版本 `0.40.16`，存在 `deepseek-r1:14b`，未下载或删除模型。
- 一次独立简单响应成功返回，证明服务可用，但响应约 95 秒。
- 初次报告和 1 秒测试均回退，固定程序事实区保持完整。
- 诊断后的手动报告复核结果为 `fallback_reason=timeout`、`used_model=False`，180 秒超时；`program_facts_text` 完整，模型叙述为 0 字。
- 因此真实模型简单响应已成功，但真实报告成功采用尚未通过；固定模板超时回退已通过。
- 后续经用户明确同意，`deepseek-r1:latest` 约 55 秒返回，但因无依据原因/预测和漏事件 ID 被回退；`deepseek-r1:14b` 约 46 秒返回，但因超过 400 字、交易指令、输入外数字 19 和漏事件 ID 被回退。两次均未自动重试，程序事实完整。
- 针对上述问题，实时提示收紧为固定行结构，默认最多 250 字，事件 ID 必填，并明确禁止固定止损被改写为卖出指令。实际值和阈值分行，重复数值也分别保留。
- 捕获真实输出后确认模型已写出两个 9；最终根因是校验器漏读紧凑 JSON 冒号后的数值。解析修复后，14B 真实结果为 `status=succeeded`、`used_model=True`、`validation_result=passed`，程序事实区完整。真实模型验收已通过。
- 滑块实际宽度从 1px 修复为 12px，并新增整页“报告成果”栏目；完整成果、程序事实和模型叙述分区展示。
- 最新全量离线测试为 **498 项通过**。
