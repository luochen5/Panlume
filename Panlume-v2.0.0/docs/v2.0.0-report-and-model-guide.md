# Panlume 2.0 Report and Model Guide (development stage)

## Language and saved records

New installations default to English. Existing Chinese settings remain in Simplified Chinese after upgrade. English, Simplified Chinese, Traditional Chinese, and Japanese are available from **Language**, applied after restart. Report presets may follow the startup language or select a language explicitly.

Historical summaries, reviews, alerts, limitations, and raw JSON remain in their original language. Interface translation never rewrites the database. Missing Japanese interface text falls back to English.

## Report Center workflow

1. Select a stock and trading date.
2. Choose **Single-stock close detail** or **Real-time event summary**. A real-time summary also requires an event check.
3. Preview the fact-package range, quality, event counts, and content SHA-256.
4. Select a preset and generate the report.
5. Export JSON or Markdown, open related event history, or manually review source evidence.

JSON retains the complete fact package. Markdown contains only the visible report selected by the preset. Hiding a section never deletes facts, raw records, or audit evidence.

## Fact-package contract

The package contains a version, report type, stock code, UTC+08:00 timezone, data range, sources, quality, confirmation status, price/volume statistics, timeline, Python indicators, rule events, read-only manually confirmed holdings, limitations, and traceability.

Every rule event includes its event/rule IDs, name, status, first and last trigger, resolution time, condition expression, observed values, thresholds, time window, merged repeat count, cooldown deadline, and evidence record IDs. Identical historical input produces identical fact content; runtime timestamps do not affect the content hash.

## Presets

Presets control detail level, length preference, visible fact sections, report language, local model name, recommendation-tier override, and custom formatting instructions. Custom instructions can only change organization; they cannot override fact integrity, numeric fidelity, or deterministic conclusions. Restoring the default preset keeps other custom presets. Presets are stored locally in `config/report-presets.json` without secret-key fields.

## Model recommendation tiers

| Parameter size | Tier | Default recommended task |
| --- | --- | --- |
| About 4B | Tier 1 | Facts, event explanation, short timelines |
| About 4–8B | Tier 2 | Structured single-stock, multi-indicator summaries |
| About 8–14B | Tier 3 | Evidence-constrained single-stock analysis |
| 14–32B | Tier 3 enhanced | Limited cross-day or multi-stock organization only when data exists |

These are recommendations, not capability certifications. Parameter size comes from Ollama metadata or an explicit model-name marker; otherwise it remains **Unknown**. A manual override does not bypass validation. Generation, quantization, and fixed-sample test results are separate fields.

## Program facts and optional model narrative

Python always generates the complete fact section first. A model can only append an optional narrative. If Ollama is disabled or unavailable, times out, returns malformed text, omits required facts, adds numbers, changes event status, confuses event time order, or produces trading instructions, unsupported causes, or predictions, only the narrative falls back. The complete fixed report remains available.

Numeric validation cannot prove that every natural-language statement is correct. Fixed historical samples and manual source-evidence review are still required.

## Ollama management

The Model page detects installation and service status, tests the connection, lists models and disk usage, selects a summary model, downloads, cancels, and deletes. Download and deletion require explicit confirmation. Failures are not retried automatically. Unknown estimated or total sizes are shown as unknown. Deletion uses only Ollama's official API; blobs and manifests are never edited directly. Fixed templates, offline demos, replay, and exports continue to work without Ollama.

## MACD and RSI

MACD defaults to `(12, 26, 9)` with first-value EMA seeding and a full warmup of `slow + signal - 1` samples. RSI defaults to 14 periods using Wilder smoothing; a constant series returns 50. Minute bars use `adjustment=none`; daily bars use `adjustment=qfq`. Missing, duplicate, unordered, gapped, mixed-timeframe, or mixed-adjustment data is never filled with invented values. The fact package records parameters, input range, sample count, evidence IDs, status, and reason.

These indicators are for public-data observation and research records only. They are not trading signals, return predictions, or investment advice.
