# Panlume v0.2.1 受控真实短验收说明

## 范围与边界

本版新增桌面“准备单次真实短验收”入口。它复用已验收的 AKShare 东方财富公开 A 股一分钟适配器，不新增服务商，不连接账户，不读取资产或交易信息，不执行外部操作。

每次计划固定：

- 一只股票；
- 当日 09:31 至用户指定终点的闭区间，固定 UTC+8；
- `stock_zh_a_hist_min_em` 接口；
- 一分钟、不复权；
- 单次执行，预计请求 1 次，自动重试 0 次；
- 全部常规分钟保持未确认；
- 独立数据库 `runtime/live-acceptance/akshare-live-test.db`；
- 独立 JSON 请求审计，保留原始行、请求参数、错误分类和实际请求数。

日期不能在未来；当日终点不能晚于当前整分钟；终点必须位于 09:31～11:30 或 13:01～15:00。程序本身不据此推断真实节假日，用户需自行核实所选日期和时段。

主库、真实持仓、Ollama 和云端不会被该入口修改或调用。模型无权生成或执行真实请求计划。

## 当次确认与防重试

生成计划只构造内存对象，不创建目录、数据库、审计或网络请求。执行前必须逐字输入：

```text
确认请求一次东方财富公开分钟并写入独立测试库
```

以下情况在联网前拒绝：

- 确认文本不一致；
- 请求范围非法；
- 计划数据库被改向主库或其他位置；
- 请求数或重试数被改动；
- 同一计划已经执行过。

一次计划只能执行一次。失败、超时或空数据后不会自动重试；确需再次请求时，必须重新生成计划、重新核对范围并再次逐字确认。

## 可选依赖

普通离线源码、测试和默认 EXE 构建不需要 AKShare。真实短验收只接受已验收版本：

```powershell
& .\.venv-build\Scripts\python.exe -m pip install -r requirements-akshare.txt
```

当前固定 `akshare==1.20.65`，程序不会自动安装、升级或降级。缺少依赖或版本不符时，会显示 `dependency_missing` 或 `dependency_version`，不会把这类问题当成真实空数据。

## 离线测试

```powershell
& .\.venv-build\Scripts\python.exe -m pytest -q -p no:cacheprovider
```

预期 `344 passed`。新增测试位于 `tests/test_desktop_live_acceptance.py` 和 `tests/test_desktop_window.py`，覆盖：

- 确认错误时零请求、零数据库、零审计；
- 固定代码、起止时间、接口参数和单次计划；
- 同一计划禁止重复使用；
- 未来日期、非交易分钟和未来终点拒绝；
- 已保存公开响应经同一门控写入独立库，主库不存在；
- 超时明确分类为 `timeout`，实际请求 1 次，重试 0 次；
- 打开准备对话框不联网、不创建真实测试库；
- 620×520 小窗口可滚动到底部，完整到达执行与取消按钮。

测试不会请求真实行情、真实 Ollama 或云端。

## Windows 构建

默认离线轻量构建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1"
```

仅在准备做真实短验收时，显式构建带依赖版本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1" -IncludeLiveData
```

后者读取 `requirements-live-build.txt`，安装并打入固定 AKShare 版本。输出便携 ZIP 带 `-live` 标记，程序目录包含 `live-data-enabled.txt`。默认构建不包含这些标记。

两种构建共用 `packaging/Panlume.iss` 制作安装包。打包前应确认 `dist\Panlume` 是本次所需变体，避免把上一次构建误当成当前版本。

## 用户真实短验收流程

1. 先完成离线测试和 EXE 启动检查。
2. 进入“观察设置”底部的“真实短验收（默认关闭）”。
3. 点击“准备单次真实短验收…”。
4. 选择一只股票，填写已核实的日期和终点。
5. 点击“生成请求计划（不联网）”，核对代码、闭区间、接口、一次请求和独立库路径。
6. 只有在当次明确同意时，输入确认文本并执行。
7. 查看结果和审计路径。失败时保留分类，不连续点击重试；再次请求必须生成新计划。

本轮源码制作和测试没有执行上述真实请求。真实联网需要在用户自己的环境中，由用户当次操作确认。
