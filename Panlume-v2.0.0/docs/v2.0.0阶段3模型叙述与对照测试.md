# Panlume 2.0 阶段 3：模型叙述接入与输出对照测试

## 本阶段完成内容

- 报告中心支持可选 Ollama 叙述区，固定程序事实区始终先生成并独立保留。
- 模型只接收事实包 JSON 副本，不能写数据库、重算指标或修改规则结论。
- 模型输出按报告类型和篇幅偏好组织，用户自定义格式说明始终从属于系统事实约束。
- 新增参数规模识别：支持 Ollama 元数据或模型名中的明确 B 标记，无法识别时为“未知”，不使用磁盘大小猜参数量。
- 默认推荐覆盖 4B～32B：一级、二级、三级、三级增强；超出范围只提示，不自动下载。
- 用户可手动覆盖推荐等级；覆盖值与自动推荐分开保存，未知/超范围覆盖仍标记为未验证。
- 模型代际、量化程度和实际测试说明使用独立 `ModelProfile` 字段，不与参数量混为一谈。
- 所有档位共用相同关键事实校验和模板回退链路。
- 报告页显示模型采用、参数规模、等级、回退原因和校验结果；原始证据按钮提供人工复核入口。
- JSON 导出分别保存 `program_facts_text`、`narrative_text`、分档、参数规模、回退与校验明细。
- 旧阶段 2 预设缺少等级覆盖字段时按自动推荐读取，不需要重置个人预设。

## 关键设计说明

1. `NarrativeService` 只返回叙述结果，`DesktopReportService` 负责把有效叙述追加到固定事实区之后；失败时最终文本等于完整固定模板。
2. 校验要求股票代码、关键日期/完整时间、每个事件 ID、原始 `active/cleared` 状态和规则关键数值。
3. 输入外数字、交易指令、无依据归因/预测、异常标签、代码块、事件遗漏、状态错误和实时时间顺序混淆均拒绝采用。
4. 同一历史事实包可对比多个模型输出，记录漏事实、错数值、错时间、错状态和无依据解释；参数规模不直接决定质量结论。
5. 数值校验不能保证所有自然语言都正确，因此保留固定样本对照、原文证据和人工复核，而不宣称完全语义正确。
6. 模型未启用时不创建客户端；模型名只在用户明确生成报告且预设非空时使用，启动不会自动调用。

## 新增或修改的测试

净增 28 项：

- 模型识别与分档：明确名称/元数据、多个标记、未知磁盘大小、4B～32B 边界、手动覆盖、独立代际/量化档案。
- 叙述校验：合法事实、错数值、漏事件、错状态、错时间、时间顺序、无依据原因和预测。
- 提示词与推荐任务：只读事实包、自定义说明从属、非能力认证、篇幅限制。
- 服务回退：有效采用、校验失败、模型禁用不创建客户端、手动等级。
- 固定样本对照：同一事实包记录各类问题，并保留代际与量化信息。
- 完整桌面报告：事实区与叙述区分层、导出字段、无效叙述只回退叙述、页面采用状态。
