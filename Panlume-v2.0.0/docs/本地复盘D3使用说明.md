# Panlume 盘灯 v0.3.0 本地复盘版 D3

## 本版范围

D3 在 D2 基础上新增桌面“本地复盘”页面：

- 手动输入六位股票代码和 `YYYY-MM-DD` 日期，生成一份本地每日复盘；
- 复用核心 `create_local_review()`，只整理 SQLite 已保存事实，不重新计算指标；
- 展示复盘编号、新建或幂等状态、数据状态、创建时间、输入 SHA-256 和完整报告；
- 最近 50 条历史按新到旧排列，点击记录可只读查看详情；
- 输入事实 JSON 继续保存在 `review_runs.input_json`，报告保存在 `local_report`；
- 空数据也允许生成，状态明确为 `unknown`，便于记录当时缺失的证据；
- 相同股票、日期和输入事实不会重复插入；证据变化后生成新的不可变复盘记录。

本地复盘不会调用 Ollama、云端或真实行情，不修改行情、指标、规则结论、摘要或持仓，也不执行交易。D2 的真实短验收仍是独立入口，保持当次逐字确认、单次请求和独立测试库。

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。真实持仓只能由用户手动确认更新，模型无权修改。敏感配置通过环境变量管理，并提供示例文件。

## 主要文件

```text
pandeng/desktop/review.py          桌面输入校验、历史读取与展示对象
pandeng/desktop/window.py          本地复盘页面和主线程 UI 队列
pandeng/review/service.py          已有确定性复盘核心，本版未改写其业务逻辑
tests/test_desktop_review.py       桌面服务、幂等和上游只读测试
tests/test_desktop_window.py       页面生成、历史选择和小窗口滚动测试
tests/test_windows_build_scripts.py 构建版本一致性检查
```

数据库结构仍为版本 6，本版没有迁移，也不会改写已有复盘。

## 源码启动

建议解压到新目录，不覆盖旧版本和个人数据：

```powershell
Set-Location D:\pandeng-d3
py -3.14 -m venv .venv-desktop
& .\.venv-desktop\Scripts\python.exe -m pip install -r requirements.txt
$env:PANDENG_DATA_DIR = "D:\pandeng-d3-acceptance-data"
& .\.venv-desktop\Scripts\python.exe desktop_launcher.py
```

该环境变量只影响当前 PowerShell 窗口及其启动的程序。首次启动只初始化隔离的个人桌面数据库，不请求行情或模型。

## 离线验收步骤

1. 打开“本地复盘”，确认启动和打开页面没有新增复盘。
2. 输入 `600000` 和一个日期，点击“生成本地复盘”。
3. 空数据库中应看到 `数据状态 unknown`、复盘编号、输入 SHA-256 和缺失证据说明。
4. 不修改数据，再次点击生成，应显示“相同输入已存在，幂等返回”，历史仍只有一条。
5. 点击历史记录，元信息应显示“历史读取”，报告和输入哈希保持不变。
6. 缩小主窗口到 980×640，页面应可滚动到报告区域。
7. 如需查看完整 `ok` 证据链，可先使用测试或模拟分析数据库；不要把独立演示数据库当成个人真实记录。

预期结果只反映已保存数据是否完整。`unknown` 不代表投资判断，空数据也不会被模型补全。

## Windows 构建

默认离线构建：

```powershell
Set-Location D:\pandeng-d3
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1"
```

输出：

```text
dist\Panlume\Panlume.exe
dist\Panlume-v0.3.0-portable-windows-x64.zip
```

仅在另行准备真实短验收时，才显式使用 `-IncludeLiveData`。该开关不会因为 D3 更新而自动启用。

安装 Inno Setup 6 后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-installer.ps1" -InnoSetupPath "D:\Inno Setup 6\ISCC.exe"
```

输出：`dist\Panlume-v0.3.0-setup-windows-x64.exe`。安装与卸载继续使用当前用户最小权限，卸载默认保留个人数据。

建议 Windows 验收顺序：完整测试 → EXE 启动 → 本地复盘新建与幂等 → 历史读取 → 小窗口滚动 → 离线观察回归 → 便携 ZIP → 安装与标准卸载 → 检查个人数据保留 → 使用现有杀毒软件正常扫描。无需关闭杀毒软件或添加大范围排除目录。

本轮源码制作和离线测试没有执行真实行情、真实 Ollama 或云端请求。Windows 成品和真实联网仍需用户在自己的环境中另行验收。
