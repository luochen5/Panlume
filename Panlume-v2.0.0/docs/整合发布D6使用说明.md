# Panlume 盘灯 v0.6.0 整合与发布候选 D6

## 本版范围

D6 整合 D1～D5 已验收能力，保留 9 个桌面入口、既有命令和数据库结构版本 6，没有新增业务策略、数据源、云端功能或复杂 Agent。

“离线演示”升级为一键整合检查，在同一独立数据库中依次完成或读取：

1. 模拟观察、指标、规则事件和断网恢复补记；
2. 根据实际规则提醒生成固定模板摘要，模型调用保持 0 次；
3. 为两只模拟观察对象生成本地复盘；
4. 只读运行数据体检；
5. 只读汇总事件与摘要历史。

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。演示中的行情和持仓均为模拟记录，不自动下单，不承诺收益。真实持仓只能由用户手动确认更新，模型无权修改。敏感配置继续通过环境变量管理，并提供示例文件。

## 数据隔离与重复运行

演示数据库固定为桌面数据目录下的：

```text
runtime\analysis-demo\analysis-test.db
```

个人桌面数据库不参与演示。首次运行会写入模拟历史、摘要和复盘；已经完成的演示再次点击时只读取结果，全部数据表保持逐行不变，不重复追加摘要或复盘。

旧版或不完整演示保持原状，程序不会自动修复、补写、覆盖或删除。空初始化库也不会被当成完整演示自动补全。需要重新体验完整流程时，换一个新的 `PANDENG_DATA_DIR` 隔离目录，不要删除旧库绕过保护。

任何失败都不会自动重试。活动任务未结束时窗口会阻止直接关闭；任务完成后可正常退出，并取消界面轮询回调。

## 源码启动

建议解压到新目录，不覆盖旧源码、个人 YAML、数据库或桌面备份：

```powershell
Set-Location D:\pandeng-d6
py -3.14 -m venv .venv-desktop
& .\.venv-desktop\Scripts\python.exe -m pip install -r requirements.txt
$env:PANDENG_DATA_DIR = "D:\pandeng-d6-acceptance-data"
& .\.venv-desktop\Scripts\python.exe desktop_launcher.py
```

环境变量只影响当前 PowerShell 窗口及其启动的程序。首次启动只初始化隔离的个人桌面数据库，不请求真实行情、Ollama 或云端。

## 一键离线验收

1. 打开“离线演示”，点击“开始／查看离线演示”。
2. 等待后台任务结束。运行期间可切换页面，但不要关闭程序。
3. 首次完整演示的预期汇总为：调度轮次 8、分析运行 14、指标快照 14、实时规则提醒 10。
4. 固定模板摘要应有任务 10 条、模板结果 10 条、模型调用 0 次。
5. 本地复盘应有 `000001` 和 `600000` 两条 `ok` 记录。
6. 数据体检总体为 `ok`，两只股票分钟均为 `240/240`，质量明细 2 条；收盘日 K 的确认语义仍按核心演示单独展示。
7. 事件与摘要历史应显示规则事件 6 条、摘要任务 10 条、模型摘要 0 条、模板回退 10 条、未完成 0 条。
8. 再次点击按钮，应看到“本次只读取结果，没有覆盖或追加”，计数不变。
9. 在 980×640 最小窗口下，9 个导航入口应完整可见，页面和结果文本均可滚动到底部。

这些数字只对应固定模拟日期 `2026-01-07` 的发布候选演示，不代表真实市场表现。

## Windows 构建

默认离线构建：

```powershell
Set-Location D:\pandeng-d6
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1"
```

输出：

```text
dist\Panlume\Panlume.exe
dist\Panlume-v0.6.0-portable-windows-x64.zip
```

只有另行准备真实短验收时，才显式使用 `-IncludeLiveData`。D6 整合演示不需要 AKShare，也不会因此开启真实请求。

安装 Inno Setup 6 后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-installer.ps1" -InnoSetupPath "D:\Inno Setup 6\ISCC.exe"
```

输出：`dist\Panlume-v0.6.0-setup-windows-x64.exe`。安装与卸载继续使用当前用户最小权限，卸载默认保留个人数据；便携版继续保留。
