# Panlume 盘灯 v0.5.0 事件与摘要版 D5

## 本版范围

D5 在 D4 基础上新增桌面“事件与摘要”页面，集中回看核心规则摘要链路：

```text
rule_events → rule_event_checks → summary_tasks → summary_results → model_calls
```

页面提供：

- 规则事件日期、代码、类型、状态、优先级、检查与提醒计数、最近确定性消息；
- 摘要任务与事件、检查、指标快照、分析运行的关联编号；
- 任务状态、模型摘要／模板回退结果、回退原因、校验记录和最终摘要；
- 输入事实 JSON、事件检查 payload JSON；
- 模型名称、调用状态、起止时间、耗时和错误元数据；
- 六位代码、可选日期、全部结果／模型摘要／模板回退／未完成筛选。

规则事件和摘要任务分别最多读取 100 条，按编号倒序展示。选择事件或任务后，在下方的“关联与摘要详情”查看对应内容。

本页只覆盖上述核心规则摘要链路。`pandeng/desktop/summary.py` 中手动观察摘要的另一条链路没有因此自动纳入本页。

## 只读与隐私边界

历史查询连接执行 `PRAGMA query_only = ON`。打开页面本身不查询，点击“刷新只读历史”后才在后台读取 SQLite 已有记录。

本页不会重新计算规则、生成摘要、恢复任务、写入业务表，也不会调用 Ollama、云端或真实行情。空历史、未完成任务、零调用模板回退和模型成功均按已有记录展示，不补造结果。

模型请求、原始响应和 R1 思考文本不在本页展开；页面只显示最终保存摘要和有限的调用元数据。数据库结构继续为版本 6，没有迁移。

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。真实持仓只能由用户手动确认更新，模型无权修改。敏感配置通过环境变量管理，并提供示例文件。

## 源码启动

建议解压到新目录，不覆盖旧版本和个人数据：

```powershell
Set-Location D:\pandeng-d5
py -3.14 -m venv .venv-desktop
& .\.venv-desktop\Scripts\python.exe -m pip install -r requirements.txt
$env:PANDENG_DATA_DIR = "D:\pandeng-d5-acceptance-data"
& .\.venv-desktop\Scripts\python.exe desktop_launcher.py
```

该环境变量只影响当前 PowerShell 窗口及其启动的程序。首次启动只初始化隔离的个人桌面数据库，不请求行情或模型。

## 离线验收步骤

1. 打开“事件与摘要”。全新隔离数据库点击“刷新只读历史”后，应显示规则事件 0 条、摘要任务 0 条。
2. 对已有模拟或离线摘要记录的数据库，可按六位代码和 `YYYY-MM-DD` 日期筛选；日期留空表示全部日期。
3. 分别选择“模型摘要”“模板回退”“未完成”，列表只显示对应任务。没有匹配记录时显示空列表和 0 条统计。
4. 选择规则事件，详情应显示指纹、状态、检查／提醒计数和最近确定性消息。
5. 选择摘要任务，详情应显示关联编号、最终摘要或尚未生成状态、输入事实和检查 payload。
6. 模型成功任务可查看模型名称、调用状态、耗时等元数据；模板回退任务可查看回退原因，零调用时明确显示“无模型调用”。
7. 缩小主窗口到 980×640，9 个导航入口应完整可见，历史页可滚动到关联与摘要详情。
8. 输入非六位代码、非补零日期或不存在的日历日期，应在打开历史查询连接前提示错误。

本页用于回看已有证据，不提供修改、删除、重试、恢复或重新生成按钮。

## Windows 构建

默认离线构建：

```powershell
Set-Location D:\pandeng-d5
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1"
```

输出：

```text
dist\Panlume\Panlume.exe
dist\Panlume-v0.5.0-portable-windows-x64.zip
```

仅在另行准备真实短验收时，才显式使用 `-IncludeLiveData`。该开关不会因为 D5 更新而自动启用，历史页面也不需要 AKShare。

安装 Inno Setup 6 后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-installer.ps1" -InnoSetupPath "D:\Inno Setup 6\ISCC.exe"
```

输出：`dist\Panlume-v0.5.0-setup-windows-x64.exe`。安装与卸载继续使用当前用户最小权限，卸载默认保留个人数据。

建议 Windows 验收顺序：完整测试 → EXE 启动 → 空历史 → 已有模拟历史筛选与详情 → 小窗口滚动 → 数据体检、本地复盘和离线观察回归 → 便携 ZIP → 安装与标准卸载 → 检查个人数据保留 → 使用现有杀毒软件正常扫描。无需关闭杀毒软件或添加大范围排除目录。

本轮源码制作和离线测试没有执行真实行情、真实 Ollama 或云端请求。Windows 成品和真实联网仍需用户在自己的环境中另行验收。
