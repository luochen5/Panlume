# Panlume 2.0 阶段 4：Ollama 图形化管理

## 本阶段完成内容

- 桌面可检测 Ollama 是否安装、服务是否运行，并显示版本、可执行文件路径和连接结果。
- 支持配置、保存和测试本地连接地址；报告叙述与观察摘要共用保存后的地址。
- 列出本地模型名称、磁盘占用、识别到的参数规模、推荐等级和量化信息。
- 参数无法识别时显示“未知”，推荐等级不作为能力认证；代际信息不由参数量猜造。
- 用户可从列表选择当前摘要模型并保存，不再仅限 `deepseek-r1:14b`。
- 支持输入准备下载的模型，下载前显示名称、预计大小（无法获得时为未知）和明确确认。
- 下载显示 Ollama 逐行返回的真实状态、已完成字节、总字节和百分比；总大小未知时使用不确定进度。
- 支持取消下载、显示失败原因并恢复按钮；不自动重试。
- 未收到 Ollama `success` 状态时按未完成处理，不把连接结束伪装成成功。
- 删除模型要求选择列表记录并再次确认，只调用正式 `DELETE /api/delete`。
- 所有长任务纳入活动任务去重和关闭保护，UI 更新回主线程。
- 不读取、移动或修改 Ollama blobs/manifests，不自动启动服务，不捆绑模型。

## 关键设计说明

1. 管理客户端只使用 `/api/tags`、`/api/version`、`/api/show`、`/api/pull` 和 `/api/delete`，不操作 Ollama 内部文件或进程。
2. 模型磁盘字节数与参数规模分开；量化从 `details` 读取，代际保留独立字段，不混为参数认证。
3. 下载生成器逐行解析有上限的 JSON；取消事件与响应关闭协作，工作线程结束后恢复界面。
4. 下载确认、删除确认都在主线程；后台线程只接收普通 Python 值，进度通过既有 UI 队列回调。
5. 连接地址使用 HTTP/HTTPS 严格校验并保存在桌面 JSON；旧设置缺少该键时继续使用原默认地址。
6. 模型名允许合法的本地名称字符，保存设置不会自动检测、下载或生成文本。
