## 关键设计说明

1. 界面翻译只处理控件和新生成固定文案，不改写 Text 中的历史记录或 SQLite 原文。
2. 报告本地化跳过原始告警与限制原文，保留证据语义和历史可读性。
3. 模型提示只转换说明部分，事实包 JSON 始终原样嵌入；日语使用独立提示与事件标记。
4. 日语缺失资源回退英文，既有中文和英文行为及测试保持通过。
5. 报告类型、事实包版本和数据库结构均未改变。
