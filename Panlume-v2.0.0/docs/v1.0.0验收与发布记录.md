- 正式版本：1.0.0。

## 发布边界

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。

真实持仓只能由用户手动确认更新，模型无权修改。

本地模型只负责摘要，不能修改原始数据和程序结论。

敏感配置通过环境变量管理，并提供示例文件。

GitHub 不发布个人 YAML、SQLite 数据库、真实持仓、审计记录、运行日志、备份、虚拟环境、验收目录、密钥或 Ollama 模型文件。

本版没有实现高 DPI 与滚动专项优化、Ollama 模型选择器、图形化模型下载、摘要客制化、事实包导出、10 只观察对象、MACD、RSI、繁体中文或日语。这些属于后续版本候选，不写入 v1.0.0 已实现功能。
