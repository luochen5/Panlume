# Panlume 盘灯 v0.2.1 桌面观察版 D2

## 本版范围

D2 保留 D1 全部桌面能力，新增：

- 观察页显式“开始离线观察／停止观察”，启动应用本身不运行轮询；
- 本地模拟分钟，最多五股，不访问网络；
- 每轮开始读取最近保存的股票和频率，运行中修改后从下一轮生效；
- 整数轮次与可中断等待，停止后不启动新请求；
- 来源、行情时间、确认状态、收盘价和入库状态表；
- 同一未确认分钟内容变化时，更新当前快照，并在 `data_quality_issues` 保存前值与后值；
- 精确重复去重；已确认分钟内容冲突、来源或复权口径变化仍拒绝覆盖；
- 手动观察摘要，只读取当前清单每只股票最近一条分钟；Ollama 失败回退 Python 固定模板；
- 主线程队列处理 Tk 回调，活动观察或摘要任务未结束时阻止直接关窗。

真实短验收采用单计划、单请求和当次逐字确认，只写独立测试库，详见 `受控真实短验收D2说明.md`。云端保持关闭。模型只整理文字，不能修改行情、指标、规则结论或持仓。

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。真实持仓只能由用户手动确认更新，模型无权修改。敏感配置通过环境变量管理，并提供示例文件。

## 安全解压与启动

建议解压到新目录 `D:\pandeng-d2`，不要覆盖 `D:\pandeng-d1`、旧虚拟环境、个人 YAML、数据库或备份。

直接运行源码：

```powershell
Set-Location D:\pandeng-d2
py -3.14 -m venv .venv-desktop
& .\.venv-desktop\Scripts\python.exe -m pip install -r requirements.txt
& .\.venv-desktop\Scripts\python.exe desktop_launcher.py
```

首次启动只初始化当前用户的桌面个人目录，不请求行情、不调用 Ollama、不访问云端。安装版默认个人数据仍位于 `%LOCALAPPDATA%\Panlume`，升级前先使用原“数据管理”页备份。

如需完全隔离源码验收，在启动前设置本次窗口的数据目录：

```powershell
$env:PANDENG_DATA_DIR = "D:\pandeng-d2-acceptance-data"
& .\.venv-desktop\Scripts\python.exe desktop_launcher.py
```

该环境变量只影响当前 PowerShell 窗口及其启动的程序。

## 离线观察验收

1. 打开“观察设置”，保留或添加 1～5 只股票，频率先选 60 秒，点击“保存观察设置”。
2. 点击“开始离线观察”。表格应显示 `simulator` 来源、完整带时区行情时间、已确认状态和模拟收盘价。
3. 第一轮完成后，已确认分钟无需重复请求；等待期间点击“停止观察”，线程应结束，状态显示已停止。
4. 再次启动，运行中修改频率或股票并保存；当前轮不中断，新设置从下一轮读取。
5. 活动观察未停止时关闭窗口会被阻止。停止并看到结束后可以正常退出。
6. 点击“生成观察摘要”。模型停用时应直接得到固定模板；启用时仅访问 `http://127.0.0.1:11434`，失败也回退模板，没有自动重试。

离线观察写入桌面个人库，来源明确为 `simulator`。它与独立“离线演示”数据库分开，也不会读取或修改真实持仓。

## 分钟修订审计

核心入库新增可选参数 `allow_unconfirmed_revisions=True`，只有桌面观察调度显式启用。必须同时满足：旧记录未确认、新记录未确认、来源相同、复权口径相同。满足后：

- `minute_bars` 保存当前快照；
- `data_quality_issues.issue_type='unconfirmed_revision'` 的 `raw_json` 保存 `before` 与 `after`；
- 修订不自动确认分钟；
- 默认旧核心调用方式不变，仍拒绝内容冲突。

## Windows 重新构建

在包含 `scripts` 和 `packaging` 的完整源码根目录执行：

```powershell
Set-Location D:\pandeng-d2
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1"
```

脚本使用独立 `.venv-build`，默认先跑完整测试，再生成：

```text
dist\Panlume\Panlume.exe
dist\Panlume-v0.2.1-portable-windows-x64.zip
```

安装 Inno Setup 6 后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-installer.ps1" -InnoSetupPath "D:\Inno Setup 6\ISCC.exe"
```

输出：`dist\Panlume-v0.2.1-setup-windows-x64.exe`。安装与卸载继续使用当前用户最小权限，卸载默认保留个人数据。Linux 沙箱测试不能代替 Windows 成品验收。

建议 Windows 验收顺序：完整测试 → EXE 启动 → 离线观察启停 → 摘要回退 → 便携 ZIP 解压启动 → 安装与标准卸载 → 检查个人数据保留 → 使用现有杀毒软件正常扫描。无需关闭杀毒软件或添加大范围排除目录。
