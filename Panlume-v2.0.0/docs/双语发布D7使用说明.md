# Panlume 盘灯 v0.7.0 双语发布候选 D7 使用说明

## 本版范围

D7 只处理语言：简体中文与 English 的桌面界面、新生成固定模板、英文 GitHub 首页及中文说明保留。数据库结构仍为版本 6，观察对象上限仍为 5 只，本地模型仍固定配置为 `deepseek-r1:14b`。

本版没有加入繁体中文、日语、摘要客制化、模型选择器、统一事实包导出、MACD、RSI、10 只观察对象或滚动性能改造，也没有改变行情、指标、规则、持仓、数据库结构和真实请求门控。

当前桌面有 10 个独立入口：总览、观察设置、本地复盘、数据体检、事件与摘要、模型与输出、语言、数据管理、离线演示、关于盘灯。

## 安全边界

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。

真实持仓只能由用户手动确认更新，模型无权修改。

本地模型只负责摘要，不能修改原始数据和程序结论。

敏感配置通过环境变量管理，并提供示例文件。

程序不自动下单，不承诺收益。启动、离线测试和离线演示不会请求真实行情、真实 Ollama 或云端。真实请求仍需当次明确确认并使用独立测试数据库，是否写主库必须由用户另行明确确认。

## 默认语言与旧配置升级

| 启动情况 | 使用的语言 |
| --- | --- |
| 公开桌面入口首次启动，设置文件不存在 | English |
| 已有设置文件包含 `"language": "zh-CN"` | 简体中文 |
| 已有设置文件包含 `"language": "en"` | English |
| 旧版设置文件存在，但没有 `language` 键 | 简体中文 |
| 语言值不是 `zh-CN` 或 `en` | 严格校验并提示，不静默改成其他语言 |

`DesktopSettings()` 自身仍默认 `zh-CN`，用于兼容旧测试和嵌入方；正式桌面入口 `main()` 对新安装显式使用英文默认值。旧 JSON 的其他偏好继续按原规则读取，不需要用户手工添加语言键。

## 独立语言板块

1. 打开左侧“语言 / Language”。
2. 在“界面语言 / Interface language”中选择“简体中文”或“English”。
3. 点击保存。
4. 正常退出并重新启动盘灯。

保存只更新桌面设置 JSON，不重建当前窗口。当前窗口的导航、按钮、状态栏和弹窗继续使用本次启动语言；本次进程内新生成的观察摘要、事件摘要、本地复盘和离线演示固定模板也继续使用本次启动语言。重启后，整个界面与新生成固定模板统一切换。

语言页面只负责语言和重启说明，不混入主题、模型、行情或清理设置。

## 文本保留规则

D7 翻译的是界面标签和新生成固定模板。以下内容保留原文：

- 已保存的模型摘要和固定模板摘要；
- 已保存的本地复盘；
- 确定性规则告警和事件消息；
- 数据质量消息、审计记录和入库详情；
- 输入事实 JSON、规则 payload、模型错误元数据；
- 原始行情、指标、规则结论、持仓和数据库结构。

英文历史页面会显示英文标签，同时明确标注“原始文本”。例如，中文摘要旁边出现英文 `Final saved summary (original text)`，摘本文本不会被翻译成英文后回写。

相同事实已经生成过中文复盘时，切换英文后再次请求会按幂等规则返回原中文复盘，不会为了显示语言另造一条记录。已有中文演示在英文界面中重新查看时，汇总标签可以使用英文，库内旧摘要和旧复盘仍是中文。需要体验完整英文模板时，使用新的隔离数据目录创建新演示。

内置英文资源缺失时，界面文案回退中文，不联网下载语言包。

## 源码启动与隔离目录

建议解压到新目录，不覆盖旧源码、个人 YAML、数据库或桌面备份：

```powershell
Set-Location D:\pandeng-d7
py -3.14 -m venv .venv-desktop
& .\.venv-desktop\Scripts\python.exe -m pip install -r requirements.txt
$env:PANDENG_DATA_DIR = "D:\pandeng-d7-acceptance-data"
& .\.venv-desktop\Scripts\python.exe desktop_launcher.py
```

环境变量只影响当前 PowerShell 窗口及其启动的程序。普通用户权限即可，不需要激活虚拟环境、管理员权限、驱动、注册表启动项或杀毒软件排除目录。

## 中英文离线验收

### 新安装英文

1. 使用一个新的 `PANDENG_DATA_DIR` 启动。
2. 标题应显示 `Panlume v0.7.0`，左侧为英文导航。
3. 状态栏应为英文，观察摘要初始提示应为 `No summary yet`。
4. “Language / 语言”应作为独立入口出现。
5. 在 980×640 最小窗口下，10 个导航按钮应完整可见，页面和结果区域可滚动。

### 切换简体中文

1. 在语言页选择“简体中文”并保存。
2. 当前窗口仍应保持英文，状态栏提示重启后生效。
3. 正常关闭并重新启动。
4. 界面应切换为中文，新生成固定模板使用中文。

从中文切换到 English 时同样检查：保存后当前窗口和本次进程的新模板仍为中文，重启后才使用英文。

### 英文一键演示

为新演示单独指定一个空目录：

```powershell
$env:PANDENG_DATA_DIR = "D:\pandeng-d7-english-demo"
& .\.venv-desktop\Scripts\python.exe desktop_launcher.py
```

确认当前启动语言为 English，再打开“Offline demo”并点击“Start / view offline demo”。首次完整结果应包含：

- scheduler rounds 8、analysis runs 14、indicator snapshots 14；
- rule events 10；
- summary tasks 10、template results 10、model calls 0；
- `000001` 和 `600000` 两条 `ok` 本地复盘；
- 两只模拟对象分钟均为 `240/240`，数据体检总体 `ok`，质量明细 2；
- 历史包含 6 条规则事件、10 条摘要任务、0 条模型摘要、10 条模板回退、0 条未完成。

演示只写独立 `runtime\analysis-demo\analysis-test.db`，个人数据库不参与。再次运行只读，不覆盖、不追加。旧版或不完整演示保持原状，不自动修复或补写。

这些数字只对应固定模拟日期 `2026-01-07`，不代表真实市场表现。

## Windows 构建与后续实机验收

默认离线构建：

```powershell
Set-Location D:\pandeng-d7
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1"
```

输出：

```text
dist\Panlume\Panlume.exe
dist\Panlume-v0.7.0-portable-windows-x64.zip
```

安装 Inno Setup 6 后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-installer.ps1" -InnoSetupPath "D:\Inno Setup 6\ISCC.exe"
```

输出：`dist\Panlume-v0.7.0-setup-windows-x64.exe`。

只有另行准备真实短验收时，才显式使用 `-IncludeLiveData`。双语离线演示不需要 AKShare，也不会因此开启真实请求。

正式 v1.0.0 前仍需在 Windows 验收：

1. 完整测试与 EXE 启动；
2. 新安装英文、旧中文设置升级、语言保存与重启；
3. 中英文一键演示及再次只读；
4. 980×640 小窗口、历史原文、复盘、体检和真实短验收弹窗；
5. 便携 ZIP 独立解压启动；
6. 安装、标准卸载、个人数据保留和最小 HKCU 项；
7. 现有杀毒软件正常扫描，不关闭防护、不添加大范围排除目录；
8. 接电源后，在盘灯内成功生成一份通过校验的 Ollama 摘要，同时保留模型失败回退验收。

Linux 源码测试和实图不能替代上述 Windows 成品结果。
