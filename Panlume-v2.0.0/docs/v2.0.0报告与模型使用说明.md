# Panlume 2.0 报告与模型使用说明（开发阶段）

## 语言与历史记录

- 新安装默认 English；已有中文设置升级后仍使用简体中文。
- “语言 / Language”支持 English、简体中文、繁體中文、日本語，保存后重启生效。
- 报告预设可跟随启动语言，也可单独指定本次报告语言。
- 历史摘要、复盘、告警、限制和原始 JSON 保留原文；界面翻译不会重写数据库。
- 日语界面缺少的文案回退英文，其他既有英文回退行为保持不变。

## 报告中心

1. 选择股票和交易日。
2. 选择“实时事件摘要”或“单票收盘详细分析”。实时摘要还需选择事件检查。
3. 点击“预览事实包摘要”核对范围、质量、事件数量和内容 SHA-256。
4. 选择预设并生成报告。
5. 可导出 JSON、Markdown，跳转相关事件历史，或打开原始证据进行人工复核。

JSON 导出保留完整事实包；Markdown 只保存当前预设控制下的展示文本。隐藏章节不会删除事实包、原始记录或审计信息。

## 统一事实包字段

- `fact_package_version`：事实结构版本。
- `report_type`、`stock_code`、`market_timezone`：报告类型、六位代码和 UTC+08:00。
- `data_range`、`source_records`、`data_quality`、`confirmed_status`：范围、来源、缺口、质量和确认状态。
- `price_volume_statistics`、`timeline`、`indicators`：Python 计算的价量、时间线和指标。
- `rule_events`：规则事件及其完整生命周期。
- `holdings_context`：只读的人工确认持仓，不包含模型写权限。
- `limitations`、`traceability`：无法确认事项、证据记录和处理链。

每条规则事件包含 `event_id`、`rule_id`、名称、状态、首末触发、解除时间、条件表达式、实际值、阈值、时间窗口、重复合并、冷却截止和证据 ID。相同历史输入生成相同事实内容，运行时间不参与事实内容哈希。

## 报告预设

- 详细程度：简洁、标准、详细。
- 篇幅偏好：较短、标准、完整。
- 显示开关：数据质量、指标明细、规则依据、时间线、条件性解释、限制与追溯。
- 报告语言、本地模型名、模型推荐等级覆盖、自定义格式说明。

自定义格式说明只控制组织方式，不能覆盖“不得新增事实、不得改数、不得修改程序结论”等系统约束。恢复默认预设不会删除其他自定义预设。预设位于个人数据目录 `config/report-presets.json`，不保存密钥。

## 模型分档

| 参数量级 | 推荐等级 | 默认推荐工作 |
| --- | --- | --- |
| 约 4B | 一级 | 事实描述、事件解释、短时间线 |
| 约 4～8B | 二级 | 单票、多指标结构化整理 |
| 约 8～14B | 三级 | 证据约束下的单票综合分析 |
| 14～32B | 三级增强 | 数据充分时有限整理跨日、多票内容 |

分档只是默认推荐，不是能力认证。参数可由 Ollama 元数据或模型名辅助识别，无法识别时为“未知”。用户可手动覆盖等级，但不会因此获得事实校验豁免。代际、量化与固定样本测试结果独立记录。

## 固定事实区与模型叙述区

报告先生成完整 Python 事实区。模型只增加可选叙述区，不修改原始记录或程序结论。以下情况只回退叙述区：

- Ollama 未启用或不可用；
- 模型超时、网络错误或响应异常；
- 缺少代码、时间、事件 ID、状态或关键数值；
- 出现输入外数字、交易指令、无依据归因或预测；
- 实时事件时间顺序混淆。

数值校验不能保证所有自然语言正确，仍需固定样本对照和人工复核原始证据。

## Ollama 图形管理

“模型与输出”可检测安装和运行状态、测试连接、列出模型、选择摘要模型、查看磁盘占用、下载、取消和删除。

下载与删除都必须明确确认；失败不自动重试；预计大小或总大小未知时显示“未知”。删除只调用 Ollama 正式 API，不修改 blobs/manifests。无 Ollama 时固定模板、离线演示、回放和导出继续可用。

## MACD 与 RSI 口径

- MACD 默认 `(12, 26, 9)`，EMA 以首值播种，满 `slow + signal - 1` 个样本后输出完整结果。
- RSI 默认周期 14，使用 Wilder 平滑；常量序列为 50。
- 分钟使用 `adjustment=none`，日线使用 `adjustment=qfq`，不得混算。
- 数据不足、乱序、重复、缺失或口径冲突时不填造数值，事实包显示状态和原因。

这些指标只用于公开数据观察和研究记录，不构成交易信号、收益预测或投资建议。
