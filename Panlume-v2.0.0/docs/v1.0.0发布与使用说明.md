# Panlume 盘灯 v1.0.0 发布与使用说明

## 正式版定位

Panlume 盘灯 v1.0.0 是首个双语公开正式版，用于公开信息处理、个人研究记录和软件学习。它保留 D1～D7 已验收的核心行为，统一版本号、安装包、便携版和发布文档。

本版没有加入 2.0 的高 DPI 改造、滚动优化、Ollama 模型选择器、图形化模型下载、摘要客制化、统一事实包导出、10 只观察对象、MACD、RSI 或附加语言。

## 普通用户安装

### 安装版

1. 下载 `Panlume-v1.0.0-setup-windows-x64.exe`。
2. 双击安装，使用默认当前用户安装位置即可。
3. 从开始菜单或可选桌面快捷方式启动。
4. 不需要安装 Python、创建虚拟环境或打开终端。
5. 标准卸载默认保留个人数据；是否删除数据由卸载时的明确选择决定。

安装版个人数据目录：

```text
%LOCALAPPDATA%\Panlume
```

### 便携版

1. 下载 `Panlume-v1.0.0-portable-windows-x64.zip`。
2. 完整解压，不要只复制其中的 EXE。
3. 进入 `Panlume` 文件夹，双击 `Panlume.exe`。
4. `Panlume.exe`、`_internal` 和 `panlume.portable` 必须一起保留。

便携版个人数据保存在与 `Panlume` 文件夹同级的 `PanlumeData`。安装版与便携版默认使用不同的数据目录。

## 首次使用

1. 新安装默认 English。
2. 如需中文，打开 **Language / 语言**，选择“简体中文”并保存。
3. 当前窗口继续使用英文，正常重启后切换为中文。
4. 打开 **Offline demo / 离线演示**，点击开始。
5. 等待结果，再次运行会只读返回，不覆盖或追加。

启动只初始化本地数据库，不请求真实行情、Ollama 或云端。离线演示只写独立 `runtime\analysis-demo\analysis-test.db`，个人数据库不参与。

## 已有功能

- 本地模拟行情观察、CSV 回放、低频调度、暂停恢复和断网补记；
- 数据质量检查、确定性指标、规则事件、冷却和事件合并；
- 手动确认的持仓批次、固定止损与 T+1；
- 固定模板摘要、可选 Ollama 摘要、事实校验与异常回退；
- 本地复盘、数据体检、事件与摘要追溯；
- 数据库备份和保守清理；
- 简体中文与 English；
- 受控真实短验收，必须由用户当次明确确认，并写独立测试数据库。

历史摘要、复盘、规则告警、质量消息、JSON 和审计记录保留原文，切换语言不会回写历史内容。

## Ollama 使用

v1.0.0 当前固定配置 `deepseek-r1:14b`。Ollama 属于可选增强，没有模型时仍可使用离线观察、确定性计算、复盘和固定模板。

1. 在“模型与输出”启用 Ollama，保存设置。
2. 点击检查 Ollama，只读取本地模型列表。
3. 在观察页取得本地模拟数据后手动生成摘要。
4. 模型不可用、超时或输出异常时自动回退固定模板。
5. 真实模型生成可能耗时较长，轻薄本建议接电源并设置合理超时。

本地模型只负责摘要，不能修改原始数据和程序结论。真实持仓只能由用户手动确认更新，模型无权修改。

## 安全边界

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。

真实持仓只能由用户手动确认更新，模型无权修改。

本地模型只负责摘要，不能修改原始数据和程序结论。

敏感配置通过环境变量管理，并提供示例文件。

程序不自动下单，不承诺收益，不构成投资建议。真实请求不自动重试，不绕过验证码或访问限制，不通过高频请求规避上游限制。云端继续默认关闭。

不需要管理员权限、驱动、注册表启动项、关闭杀毒软件或大范围排除目录。不要擅自删除、移动或修改 Ollama 模型文件、现有数据库、个人 YAML、虚拟环境和备份。

## 开发构建

普通用户无需执行本节命令。开发者从源码构建 Windows 成品时：

```powershell
Set-Location D:\pandeng-v1
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-installer.ps1" -InnoSetupPath "D:\Inno Setup 6\ISCC.exe"
```

输出：

```text
dist\Panlume\Panlume.exe
dist\Panlume-v1.0.0-portable-windows-x64.zip
dist\Panlume-v1.0.0-setup-windows-x64.exe
```

Windows EXE 必须在 Windows 构建。默认构建不包含可选真实行情依赖；只有另行准备受控真实短验收时才显式使用 `-IncludeLiveData`。
