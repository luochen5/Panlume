# Panlume 盘灯 v0.4.0 数据体检版 D4

## 本版范围

D4 在 D3 基础上新增桌面“数据体检”页面：

- 手动选择日期和截止交易分钟，检查当前观察清单中的全部股票；
- 复用核心 `audit_market_data()`，保留已有日历、完整性、确认状态和价格线判断；
- 展示每股应有／已保存／已确认／未确认分钟数、缺口、分钟来源、连续检查点和日 K 状态；
- 当日质量明细最多显示 100 条，相关入库批次最多显示 100 条；
- 选择质量行可查看问题编号、关联批次、级别、类型、数据时间、消息和原始 JSON；
- 选择批次行可查看适配器、创建时间及收到、接受、去重、拒绝计数；
- 空数据、缺口、未确认和质量冲突继续显示核心结论，不自动补全证据。

本版只读取 SQLite 已有记录，没有补数、修复、写表、模型、云端或真实行情调用入口。数据库结构仍为版本 6，没有迁移。

项目只用于公开信息处理、个人研究记录和软件学习，不连接外部账户，不执行外部操作。真实持仓只能由用户手动确认更新，模型无权修改。敏感配置通过环境变量管理，并提供示例文件。

## 源码启动

建议解压到新目录，不覆盖旧版本和个人数据：

```powershell
Set-Location D:\pandeng-d4
py -3.14 -m venv .venv-desktop
& .\.venv-desktop\Scripts\python.exe -m pip install -r requirements.txt
$env:PANDENG_DATA_DIR = "D:\pandeng-d4-acceptance-data"
& .\.venv-desktop\Scripts\python.exe desktop_launcher.py
```

该环境变量只影响当前 PowerShell 窗口及其启动的程序。首次启动只初始化隔离的个人桌面数据库，不请求行情或模型。

## 离线验收步骤

1. 打开“数据体检”，确认页面显示当前观察对象，启动和打开页面不会生成体检报告。
2. 输入一个 `YYYY-MM-DD` 日期和交易分钟，例如 `2026-01-12`、`09:33`。
3. 点击“开始只读体检”。空数据库应显示 `unknown`，并说明目标分钟缺失；不会补造分钟或日 K。
4. 若数据库已有模拟或离线入库记录，报告会按核心规则显示 `ok`、`price_only` 或 `unknown`。日 K 单独显示，不与分钟状态混用。
5. 有质量记录时，在“当日质量明细”选择一行，追溯详情应显示原始 JSON。
6. 在“相关入库批次”选择一行，追溯详情应显示适配器与接收计数。
7. 缩小主窗口到 980×640，页面应可滚动到报告、明细和追溯详情。
8. 输入 `09:30` 或 `12:00`，应在读取详细证据前提示交易分钟无效；输入非补零时间或非六位观察代码也会被拒绝。

状态含义：

- `ok`：应有分钟完整且确认，交易日历明确开市，区间内没有质量错误；
- `price_only`：历史序列存在缺口、未确认或质量错误，但目标分钟有效、确认且无目标质量冲突，当前价格线仍可使用；
- `unknown`：目标分钟缺失、未确认或存在质量冲突，价格线保持未知；日历明确休市时也不开放价格线。

报告按当前数据库回看，不能证明数据在当时已实时到达。质量与批次列表用于定位已有证据，不提供修改或删除按钮。

## Windows 构建

默认离线构建：

```powershell
Set-Location D:\pandeng-d4
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-windows.ps1"
```

输出：

```text
dist\Panlume\Panlume.exe
dist\Panlume-v0.4.0-portable-windows-x64.zip
```

仅在另行准备真实短验收时，才显式使用 `-IncludeLiveData`。该开关不会因为 D4 更新而自动启用，数据体检页面本身也不需要 AKShare。

安装 Inno Setup 6 后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\build-installer.ps1" -InnoSetupPath "D:\Inno Setup 6\ISCC.exe"
```

输出：`dist\Panlume-v0.4.0-setup-windows-x64.exe`。安装与卸载继续使用当前用户最小权限，卸载默认保留个人数据。

建议 Windows 验收顺序：完整测试 → EXE 启动 → 空数据体检 → 已有模拟数据体检 → 质量与批次选择 → 小窗口滚动 → 本地复盘和离线观察回归 → 便携 ZIP → 安装与标准卸载 → 检查个人数据保留 → 使用现有杀毒软件正常扫描。无需关闭杀毒软件或添加大范围排除目录。

本轮源码制作和离线测试没有执行真实行情、真实 Ollama 或云端请求。Windows 成品和真实联网仍需用户在自己的环境中另行验收。
