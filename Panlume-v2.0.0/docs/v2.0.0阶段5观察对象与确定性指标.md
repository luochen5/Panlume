# Panlume 2.0 阶段 5：10 个观察对象、MACD 与 RSI

## 本阶段完成内容

- 桌面观察列表从最多 5 个扩展到最多 10 个，达到上限时明确提示。
- 支持图形化添加、删除、启停、上移和下移，保存后保留顺序与启停状态。
- 旧桌面 JSON 缺少 `enabled` 时默认启用，已有对象与顺序保留。
- 调度只处理启用对象，仍沿用 60～3600 秒原频率设置，不因数量增加自动提高请求频率。
- 新增确定性 MACD，默认 `(12, 26, 9)`；新增 Wilder RSI，默认周期 14。
- YAML 新增可选 `indicators` 板块，旧配置缺省时使用默认参数并校验合法性。
- 分钟仅使用 `adjustment="none"`，日线仅使用 `adjustment="qfq"`，股票、周期和口径不得混算。
- 数据不足返回 `insufficient_data`，无效/缺失/乱序/重复/缺口返回 `invalid_data`，不填造数值。
- 事实包记录 MACD/RSI 参数、输入范围、有效样本数、来源证据 ID、状态和原因。
- 中文与英文详细报告均展示分钟及日线 MACD/RSI；实时报告展示对应分钟结果。
- 未新增业务策略、交易信号、收益预测或自动交易逻辑。

## 关键设计说明

1. MACD 使用首值作为 EMA 初始值，满 `slow + signal - 1` 个样本后输出完整 MACD、信号线与柱值。
2. RSI 使用 Wilder 初始均值与后续平滑；常量序列 RSI 为 50，平均损失为 0 且存在上涨时为 100，平均上涨为 0 且存在下跌时为 0。
3. 纯计算函数与数据库读取分离。输入记录统一检查股票、周期、复权、有限正收盘价、时间和证据 ID 唯一性。
4. 分钟按当日明确交易分钟检查连续性；日线按确认前复权记录和开市日历检查连续性，不能跨缺口补写。
5. 报告只调用 Python 计算结果，模型没有另一套指标公式或重算权限。
6. 观察启停只影响桌面调度与观察摘要，历史数据和报告选择不被删除或改写。
