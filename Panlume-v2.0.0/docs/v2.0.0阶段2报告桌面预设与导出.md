# Panlume 2.0 阶段 2：报告桌面入口、预设与导出

## 本阶段完成内容

- 新增桌面“报告中心”，导航从 10 项增加到 11 项，最小窗口自动测试确认所有按钮可见。
- 支持选择股票、交易日、报告类型和事件检查，分别生成实时事件摘要与单票收盘详细分析。
- 支持事实包摘要预览、报告预览、JSON 导出、Markdown 导出、相关事件历史跳转和原始证据窗口。
- JSON 导出包含完整事实包、事实内容 SHA-256、报告文本、显示预设、模型采用状态、回退原因和校验状态。
- 新增独立严格 JSON `config/report-presets.json`，不修改既有桌面设置结构，不保存密钥字段。
- 预设支持详细程度、篇幅偏好、六个显示章节开关、报告语言、本地模型偏好和自定义格式说明。
- 支持保存命名预设和恢复默认预设；恢复默认不会删除其他自定义预设。
- 显示预设只过滤展示内容，完整事实包、证据 ID 和原始数据库记录保持不变。
- 阶段 2 始终使用固定模板；模型偏好只保存，不因选择模型而自动调用 Ollama。
- 保持版本号 1.0.0 和数据库结构 6，无数据库迁移。

## 关键设计说明

1. 预设文件使用 `pandeng.report-presets.v1` 格式，严格拒绝未知/缺失字段、非布尔开关、重复名称和错误版本，采用临时文件原子替换。
2. 报告生成与事实包生成共用 `DesktopReportService`，没有另建规则或指标路径。
3. 事实包预览和导出包含完整事实；模板显示选项只控制质量、指标、规则依据、时间线、条件性解释、限制与追溯的可见性。
4. 原始证据窗口只读展示部分原始 `raw_json`、规则检查和分析运行，事实包仍保留全部证据 ID。
5. 报告页所有 Tk 变量都在主线程读取后转换为普通 Python 参数，再交给工作线程；界面回调继续通过既有 UI 队列回主线程。
6. 新任务纳入 `active_tasks` 去重、按钮恢复、错误日志和关闭保护。事件历史跳转会选中并显示对应事件详情。
7. 中英文控件使用集中翻译资源，报告模板继续使用启动语言或预设明确指定的语言。

## 新增或修改的测试

新增 12 项：

- 预设 5 项：默认/往返、恢复默认、严格字段、错误版本/重复名称、完整显示选项。
- 桌面报告服务 4 项：详细报告与两种导出、实时事件匹配、隐藏章节但事实包不变、错误后缀。
- Tkinter 页面 3 项：预览/生成/导出/原始证据/历史跳转、实时事件与预设、英文控件和英文模板。

修改既有桌面导航测试：要求 11 个入口均存在并可见，不再固定为旧版 10 个。

开发中还修复并回归了两个实际问题：

- 通用任务回调中的按钮循环变量与任务名冲突，导致任务无法收尾；
- 工作线程直接读取 `StringVar`，导致 `main thread is not in main loop`。
